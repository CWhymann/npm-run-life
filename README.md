# npm run life

A song ("Alles Neu") turned into an interactive terminal crawl in the browser: lyrics scroll Star Wars-intro style in sync with the music, backed by a Matrix-style rain background, neon effects, and CRT flash moments during the chorus.

## Demo

Live: https://cwhymann.github.io/npm-run-life/

## Features

- Typewriter-style terminal crawl text, synced to audio playback
- Matrix rain background (Canvas)
- Play/pause, seek bar, mute
- CRT flash and shake effects at chorus lines and at the end

## Usage

Just open `index.html` locally in a browser, or visit the hosted version. No build steps, no backend — plain HTML/CSS/JS.
